# Primer Impacto — Technical tests

This repository hosts our take-home technical tests. Depending on the role you're applying for, go to the matching folder — each has its own README with the full brief.

| Role | Folder |
|---|---|
| **Data Analyst** | [`/data-analyst-test`](./data-analyst-test) |
| **Data Engineer** | [`/data-engineer-test`](./data-engineer-test) |

If you're not sure which one applies to you, check the email/message where you received the link to this repo, or ask us — don't do both.

## Getting started (both tests)

1. Fork this repository to your own GitHub account.
2. Clone your fork and work only inside the folder for your test.
3. When done, push to your fork and reply to the email thread where you received the test with your fork URL.

Good luck!
